# Trappole

Raccolte di errori già pagati in questo repo (app PDF Pro). Ogni voce ha sintomo, causa e cosa fare. Leggi il file pertinente prima di toccare l'area.

- [`prezzi-e-asc.md`](prezzi-e-asc.md): leggilo quando tocchi prezzi, prove gratuite, prodotti IAP, testi/screenshot dello store, app info, deliver/`fastlane metadata`, invio in review o rifiuti Apple.
- [`firma-e-release.md`](firma-e-release.md): leggilo quando archivi, firmi, esporti o carichi una build (`fastlane beta/release/profiles/upload_ipa`), o lanci `xcodebuild` da terminale.
- [`cataloghi-e-lingue.md`](cataloghi-e-lingue.md): leggilo quando modifichi `Localizable.xcstrings`, aggiungi una lingua o allinei le schede dello store alle lingue dell'app.
- [`swiftui-e-pdfkit.md`](swiftui-e-pdfkit.md): leggilo quando tocchi presentazioni/sheet/toolbar SwiftUI, layout con coordinate, PDFKit e annotazioni, scanner/fotocamera o editor pagine.
- [`test-e-verifica.md`](test-e-verifica.md): leggilo quando scrivi UI test, rifai gli screenshot dello store, provi l'app in simulatore (Vision, StoreKit) o devi verificare che qualcosa funzioni davvero.
- [`dati-e-metriche.md`](dati-e-metriche.md): leggilo quando interroghi Grogu, le notifiche Apple (ASSN) o GA4, o interpreti conversioni, installazioni, checkout e retention.
